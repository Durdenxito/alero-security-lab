# Video de demostración

Duración objetivo: entre 2 y 4 minutos, máximo 5. El MP4 preparado localmente contiene narración y capturas de la aplicación, su implementación y los resultados reales.

1. **Presentación:** Folio es una biblioteca personal estática, con búsqueda, progreso y respaldo JSON. Mostrar la interfaz.
2. **Uso:** abrir el registro de un libro, mostrar páginas y filtros. Explicar que los datos se guardan en el navegador.
3. **Construcción:** HTML, CSS y módulos nativos. El build limpia el destino y copia una lista explícita de archivos. Mostrar el script real.
4. **Análisis:** ZAP Baseline pasivo y tres plantillas oficiales de Nuclei. Mostrar los resultados del control y del artefacto final.
5. **Interpretación:** desaparece la exposición de Git del control; siguen los avisos de cabeceras. Diferenciar CSP en HTML de cabeceras HTTP.
6. **Automatización:** mostrar pruebas y workflow de Pages. Indicar que el despliegue está preparado para activación manual.

Para finalizar la entrega pública: desplegar Pages, añadir una captura del sitio real, publicar el video con acceso público, sustituir el estado pendiente por su URL y publicar el artículo. Compartir ambos enlaces en Telegram y empaquetarlos en ZIP. No usar una dirección prevista como prueba de una publicación completada.
